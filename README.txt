PREVIEW: Open index.html in a browser.
PUBLISH: Upload the entire unzipped jason-sedgwick-music folder to Netlify Drop, or deploy the ZIP if your Netlify workflow supports it.

4. Review image choices. Upcoming covers are conceptual. The Borrowed Time graphic is a promotional image, not necessarily the clean final single cover.
